Ten readings of one screen

One sidebar for configuration, one main pane for what is running, no tabs. The sidebar holds the policy — the agents, the models, the harness, the review-round limit, the order. The main pane holds the run — the crew, the round, the budget, the findings, the queue. Ten proposals, ten different answers to what leads and what sits beside what. Every number is computed from mock-data/coding-crew/work/: 16 live tasks, 1 claimable (TSK29), 21 open findings (8 high, 8 medium, 5 low), a review budget of 5 external rounds — 3 tasks at 1/5, 3 spent at 5/5. The crew is runtime state: 3 agents — one per role.
