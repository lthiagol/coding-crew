# Terminal columns: the one table both measures of a line's terminal width
# read. scripts/pty-sweep.py reads it to sweep raul's plain render, and
# crates/raul/tests/render_plain.rs reads it to check the rendered lines.
#
# The rules are the `rule` lines below; the ranges under them are those rules
# unrolled. A `rule` line is
#
#   rule NAME WIDTH SELECTOR ARG...
#
# applied in the order written: the first rule holding a codepoint gives its
# columns. WIDTH is 0, 1, 2, `tab` or `join`. SELECTOR is `category` for
# Unicode general categories, `east-asian-width` for East Asian Width classes,
# or `range` for hex codepoint ranges. `rule default W` gives the width of a
# codepoint no other rule holds; the range readers take one when no range
# holds a codepoint, so W is one. `rule join-after CP` names the codepoint
# after which the next codepoint joins the cluster before it, so a joined
# emoji counts once. `rule presentation-selector CP` names the codepoint that,
# after the cluster before it, makes that cluster take two columns: an emoji
# presentation. `rule tab-stop N` is the stop a tab advances to; a tab is
# measured by its position in the line, not by itself.
#
# The ranges below are the rules unrolled: the first range holding a
# codepoint gives its columns, and a codepoint in no range takes the default
# of one. `join` is a codepoint that continues the cluster before it and
# adds no column. The ranges were generated by applying the rules above to
# every codepoint with Python 3.15.2's unicodedata (Unicode 17.0.0), by
# scripts/generate-terminal-columns.py, which the gate runs; "tab" is one
# cell that advances to the next tab stop. Different Unicode data is a
# different table, so the generator refuses to check the ranges under it.
#
# The cases at the foot pin the rules on the characters the two measures
# used to disagree about, and on the ordinary characters around them. Each
# line is: case NAME CODEPOINTS EXPECTED_COLUMNS (hex codepoints, comma
# separated, measured from column zero).

rule tab-stop 8
rule join-after 200D
rule presentation-selector FE0F
rule tab tab range 0009-0009
rule conjoining-hangul-vowel-and-trailing join range 1160-11FF D7B0-D7C6 D7CB-D7FB
rule control 0 category Cc
rule combining-and-format join category Mn Me Cf
rule emoji-modifier join range 1F3FB-1F3FF
rule wide-and-fullwidth 2 east-asian-width W F
rule default 1
