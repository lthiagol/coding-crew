# Terminal columns: the one table both measures of a line's terminal width
# read. scripts/pty-sweep.py reads it to sweep raul's plain render, and
# crates/raul/tests/render_plain.rs reads it to check the rendered lines.
#
# The rules, decided once here:
#   - a combining mark (Mn, Me) adds no column;
#   - a format character (Cf), including a zero-width joiner and a soft
#     hyphen, adds no column;
#   - a control character (Cc) adds no column;
#   - a wide or fullwidth character (East Asian Width W or F) takes two;
#   - every other character takes one;
#   - a tab advances to the next tab stop. tab-stop is the number below, and
#     a tab is measured by its position in the line, not by itself.
#
# The measure is per Unicode codepoint, not per grapheme cluster: a ZWJ
# sequence adds its codepoints' columns, with the joiner adding none.
#
# The ranges below are the one- and two-column rules unrolled: the first
# range holding a codepoint gives its columns, and a codepoint in no range
# takes the default of one. They were generated by applying the rules above
# to every codepoint with Python 3.15.2's unicodedata
# (Unicode 17.0.0). "tab" is one cell that advances to the next
# tab stop.
#
# The cases at the foot pin the rules on the characters the two measures
# used to disagree about, and on the ordinary characters around them. Each
# line is: case NAME CODEPOINTS EXPECTED_COLUMNS (hex codepoints, comma
# separated, measured from column zero).
